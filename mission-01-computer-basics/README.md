# Mission 1 — Know Your Computer

## 1. Mission Title
Know Your Computer

## 2. Task / Objective
Understand how a computer receives input, processes information, produces output and stores data. Identify hardware, software and computer-based systems used in everyday life.

## 3. Work Completed

### Task 1.1 — IPOS

Activity chosen: Typing and saving a document.

| Stage | What happens? | Hardware / Component |
|---|---|---|
| Input | I enter text using the keyboard. | Keyboard |
| Processing | The processor handles the information and memory temporarily stores the working data. | CPU and RAM |
| Output | The document appears on the screen. | Monitor |
| Storage | The document is saved for future use. | SSD |

The keyboard sends input to the computer. The CPU processes the information, and the screen displays the result. Finally, the document is saved on the SSD.
